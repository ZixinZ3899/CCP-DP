## Benchmark status

RobuSeqNet is not included in the validated benchmark results.

A verified pretrained checkpoint for the evaluated datasets was unavailable.
Earlier custom cross-validation experiments did not reproduce a valid
RobuSeqNet baseline and are therefore not distributed as reported results.

The upstream project did not expose a clear redistribution license during
migration. Its source is therefore fetched directly from the upstream
repository instead of being copied into this repository.
